# CPA Pricing Analytics｜會計師事務所智慧報價分析

這是一個結合會計師事務所實務與資料分析，並運用 AI 程式開發工具完成的公開作品集專案。

系統將歷史案件整理成結構化資料，使用對數線性迴歸分析影響服務成本與報價的因素，並提供可解釋的建議價格與區間。

> 本公開版本的公司名稱與財務數據全部為合成示範資料，不包含任何客戶、案件或事務所機密資訊。

## 作品集重點

- 將會計專業知識轉化為可操作的產品流程
- 在瀏覽器中以 JavaScript 實作對數線性 OLS（Gaussian elimination）與留一交叉驗證
- 呈現 R²、Adjusted R²、RMSE、交叉驗證誤差、係數及因子貢獻；資料變化不足的因子自動排除
- 報價超出歷史資料範圍時提醒，建議區間以比例呈現
- 匯出各客戶實際報價與模型預測的差距表（CSV）
- 匯入時可選擇取代或附加，並可一鍵清空資料
- 支援 CSV 與已發布的 Google Sheets CSV 資料
- 純前端架構，無後端、無建置步驟，可部署於 GitHub Pages
