Data Collection Guide

Recommended columns for preparing engagement data in Excel and importing it as CSV.

Monthly Bookkeeping Columns

Column Description Format / values
company Client name Text
date Engagement month YYYY-MM
monthly_vouchers Vouchers processed per month Integer, e.g. 200
revenue_level Monthly revenue band 1 = under NT$0.5M, 2 = NT$0.5M–2M, 3 = NT$2M–5M, 4 = NT$5M–100M, 5 = over NT$100M
employee_count Headcount Integer
industry Industry 1 = Services, 2 = Wholesale & retail, 3 = Manufacturing, 4 = Construction, 5 = Financial services, 6 = Other, 7 = Holding company, 8 = Investment advisory
add_tax_vat Add-on: business tax (VAT) filing 0 = no, 1 = yes
add_tax_withholding Add-on: withholding tax filing 0 = no, 1 = yes
add_invoice Add-on: invoice issuance 0 = no, 1 = yes
add_payroll Add-on: payroll processing 0 = no, 1 = yes
staff_quality Client accounting staff quality 10 = A+, 9 = A, 8 = A−, 7 = B+, 6 = B, 5 = B−, 4 = C+, 3 = C, 2 = C−, 1 = D
major_tax_issue Major tax adjustment 0 = no, 1 = yes
price Monthly fee (NT$) Integer, e.g. 8000

Annual Tax Attestation Columns

Column Description Format / values
company Client name Text
date Engagement month YYYY-MM
total_assets Total assets (NT$10k) Number, e.g. 500 = NT$5M
annual_revenue Annual revenue (NT$10k) Number, e.g. 1200 = NT$12M
industry Industry 1 = Services, 2 = Wholesale & retail, 3 = Manufacturing, 4 = Construction, 5 = Financial services, 6 = Other, 7 = Holding company, 8 = Investment advisory
first_audit First-year engagement 0 = no, 1 = yes
staff_quality Client accounting staff quality 10 = A+, 9 = A, 8 = A−, 7 = B+, 6 = B, 5 = B−, 4 = C+, 3 = C, 2 = C−, 1 = D
major_tax_issue Major tax adjustment 0 = no, 1 = yes
financial_audit Includes financial statement audit 0 = no, 1 = yes
audit_risk Tax audit risk 1 = low, 2 = medium, 3 = high
price Annual fee (NT$) Integer, e.g. 50000

How to Prepare Your Data

1
Create one sheet per service (bookkeeping and tax attestation) and use the column names in the first column above exactly as written.
2
Save each sheet as CSV: in Excel, File → Save As → CSV (comma delimited).
3
At least 5 records are needed to run the regression. 20 or more gives noticeably more stable estimates, and cross-validation is shown from 10 records.
4
Score accounting staff quality on this scale:
A+ = 10 A = 9 A− = 8 B+ = 7 B = 6 B− = 5 C+ = 4 C = 3 C− = 2 D = 1
5
You can also enter records by hand with Add Engagement; CSV import is optional.
